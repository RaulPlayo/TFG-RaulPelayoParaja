# Capitulo 3 - Requerimientos y Requisitos

[Volver al indice principal](../README.md)

---

En este capitulo se representan los conceptos más relevantes del sistema y las relaciones entre ellos. El dominio del proyecto gira en torno a tres grandes conceptos: los datos que gestiona la plataforma EMI Suite 4.0 de Soincon, los eventos que se generan cuando estos datos cambian, y las notificaciones que el sistema entrega al responsable del centro de control como consecuencia de esos eventos.
